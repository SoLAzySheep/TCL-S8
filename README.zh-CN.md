# TCL S8 屏幕校色 1.0

| **简体中文** | [English](README.en.md) |
|:---:|:---:|

TCL S8 屏幕校色是一款面向 TCL NXTPAPER S8 的 Android 屏幕调节工具。它通过设备提供的 MediaTek PQ 与 Android 显示接口调整图像参数，并提供主界面和悬浮窗两种操作方式。

## 功能

- 调节对比度、饱和度、Gamma、图像亮度、锐度、蓝光强度及 RGB 增益。
- 调节 Gamma LUT 曲线，范围为 0%–200%；100% 会恢复当前 Gamma 索引对应的原厂曲线。该曲线通道不提供硬件读回值。
- 控制色彩模式、动态对比度及 Android 颜色反转。
- 通过悬浮面板在其他应用上方预览并调整 PQ 参数；主界面和悬浮窗同步参数数值。
- 从主界面或悬浮窗应用推荐配置，或恢复设备 PQ 默认参数。
- 点击参数数值可输入绝对值。

## 使用要求

- 需要 Root 权限，并在 Root 管理器中允许 `com.codex.s8tuner` 获取超级用户权限。
- 使用悬浮窗需要授予“显示在其他应用上层”权限。
- 当前主要针对 TCL NXTPAPER S8 `9288A_EEA / Da_Vinci_4G` 固件验证。其他机型及固件未经验证。
- Chameleon 控件受设备驱动限制；当前 S8 驱动可能拒绝非零强度写入。应用会以设备实际可用状态为准。

## 风险提示

本软件通过 Root 权限调用显示控制接口。参数效果和接口可用性取决于设备、系统版本及驱动；不受支持的写入可能被拒绝。Root 操作和显示调节可能影响设备运行或画面效果，请自行评估并承担风险。本软件按现状提供，不附带任何担保。
